# Telegram-бот CRUMB

Проект использует шаблон бота для пекарни: меню услуг, форма заявки, каталог Mini App, админ-панель и опциональный ИИ-консультант. Шахматный бот и Mini App сохранены в `chess-backup/`.

## Windows

Запусти `run.bat`. Он запросит токен, числовой Telegram ID администратора и HTTPS-ссылку Mini App, затем установит зависимости и стартует бота. Не публикуй токен и не сохраняй его в GitHub.

## Настройка

- Тексты и название: `config_texts.py`
- Каталог Mini App: `miniapp/index.html`
- Информация для ИИ: `knowledge.txt`
- Пример переменных окружения: `.env.example`
- Зависимости: `requirements.txt`

ИИ по умолчанию выключен. Для заявок и заказов укажи свой Telegram ID при запуске. На Render добавь `BOT_TOKEN`, `ADMIN_ID` и `WEBAPP_URL` в Environment.

Персональные данные и заказные списки хранятся в локальных JSON-файлах. На бесплатном хостинге они могут сброситься при перезапуске.
